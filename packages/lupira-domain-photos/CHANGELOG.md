# Changelog

## 0.2.0

- `eventPhotoWindow(item, now?)` returns null for an event that hasn't begun by `now` (default: the current time), so galleries offer no photos for future events.

## 0.1.0

- `photoWindow`: `eventPhotoWindow`, `captureWindow`, `PHOTO_SUGGEST_LIMIT`, `EVENT_CANDIDATE_LIMIT`.
- `photoLinks`: `PHOTO_LINK`, `PHOTO_TEXT`, `linkPhotosTitle`, `linkedMessage`, `seeAllLinked`.
